## 📖 About This Repository

Welcome to the **C Programming Mastery** repository!

This repository is a structured learning resource that covers everything from the basics of C to advanced programming concepts. Every program is written with readability, proper formatting, and comments so that learners can easily understand the logic.

Whether you are:

* 🎓 A student learning C for the first time
* 💼 Preparing for technical interviews
* 🧠 Practicing Data Structures & Algorithms
* 🏆 Preparing for coding competitions
* 👨‍💻 Strengthening your programming fundamentals

this repository aims to be your one-stop resource.

# ▶️ How to Run

### Clone the Repository

```bash
git clone https://github.com/your-username/C-Programming.git
```

### Navigate to the Project

```bash
cd C-Programming
```

### Compile

```bash
gcc filename.c -o program
```

### Run

Linux / macOS

```bash
./program
```

Windows

```bash
program.exe
```
